Selected work

Five things I'd want to be judged on.

Platform

Serverless GPU inference at a million images a month

Three greenfield platforms — image, 3D and AutoQC — on one event-driven backbone: SQS into an EventBridge Pipe, into Step Functions, into AWS Batch across Fargate CPU and EC2 GPU. Each is its own Terraform monorepo with per-AZ workspace isolation, a three-pool L4/L40S GPU topology, Triton inference sidecars, and an SSM-backed AMI registry that turns a GPU image roll into a two-parameter change. It replaced an always-on GPU fleet.

  • 93% cheaper per image than the fleet it replaced
  • 6,669 images/hr sustained
  • 216K images delivered in 24h
  • 5-way parallel GPU fan-out
Security

Shipping edge controls without breaking production

Authentication controls at the edge, on the WAF in front of our public load balancer. I rolled them out the careful way — running the rule in observation mode across a quarter of a million real requests and reading the results before enforcing anything, which is how I caught a legacy dependency a straight cutover would have broken. Alongside it, Project Shield ended shadow IT by moving internal and agentic applications onto governed, Terraform-only AWS with business-unit segregation.

  • 242K requests analysed before enforcing
  • Zero production impact at rollout
  • Multi-account Identity Center as code
  • Foundation for SOC 2 and GDPR
Reliability

From firefighting to an operating model

The function was absorbing four to five incidents a day — a support queue, not a platform team. I rebuilt the function around on-call rotations with per-team schedule sync, real RCA discipline, branch protection and merge governance, a deployment freeze policy, and golden-path deployment docs. Then I automated the lifecycle: a PagerDuty to Jira to Slack pipeline with fingerprint deduplication, a reopen window, and automatic RCA ticketing.

  • Monthly incident volume down ~85%
  • Recovered a 14-hour EKS outage, all 43 models
  • Global Accelerator failover during the Cloudflare outage
  • ~1,400 LOC, 62+ tests
Cloud economics

Making the bill stop growing

Spend had been climbing by a double-digit percentage every single month. Rather than trimming line items, I went after the structure: retired a GPU service outright, downsized GPU tiers while holding throughput, killed a 35-million-message queue pendency loop before it reached the invoice, and co-located hot-path storage in a single AZ to remove cross-AZ transfer entirely. I also negotiated commercial credit directly with AWS alongside our finance team.

  • Growth curve flattened to +0.9%
  • Commercial credit negotiated with AWS
  • Per-batch and per-image cost instrumented
  • Built the cost dashboard the org now runs on
Governance

Quality gates across an entire GitHub org

I audited all 179 repositories in the org and rolled a shared CI workflow — tests, coverage and static analysis — into every one where it genuinely applied, documenting why each exclusion was an exclusion rather than quietly skipping it. Paired with a GitHub App I wrote that blocks any pull request without a valid Jira link, and declarative org-wide team permissions.

  • 179 repositories audited
  • 110 projects under quality gates
  • Custom Node.js GitHub App
  • Rulesets and RBAC as config
